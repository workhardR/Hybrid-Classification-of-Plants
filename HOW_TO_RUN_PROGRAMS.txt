1. INITIAL COMMAND PROMPT SETUP (DO THIS FIRST)
================================================================================
Open Command Prompt (Press Win + R, type `cmd`, and press Enter).
Always navigate to the project directory and activate the virtual environment:

Command to navigate to project root:
------------------------------------
cd /d C:\Users\ronit\Downloads\plant_hybrid_project

Command to activate the virtual environment:
--------------------------------------------
.venv\Scripts\activate

(After running this, you should see "(.venv)" appear at the start of your command prompt line)

(Optional) To install or verify all dependencies:
-------------------------------------------------
pip install -r requirements.txt


================================================================================
2. WEB APPLICATION (FLASK BROWSER INTERFACE)
================================================================================
Launches the interactive web application with:
  - Image upload & real-time botanical classification
  - CLAHE contrast enhancement preview
  - Overfitting / Underfitting detection indicators
  - Side-by-side 7 hybrid algorithm comparison

Command to start:
-----------------
python app.py

How to open in browser:
-----------------------
Once running, open your web browser (Chrome, Edge, etc.) and go to:
http://127.0.0.1:5000

To stop the web application:
Press Ctrl + C in the Command Prompt window.


================================================================================
3. COMPLETE 10-STEP MACHINE LEARNING PIPELINE
================================================================================
The project implements a 10-step academic workflow for dataset loading,
leakage checking, CLAHE enhancement, GAN augmentation, training, and evaluation.

Option A: Run ALL 10 Steps Automatically in Sequence
-----------------------------------------------------
python run_all_pipeline_steps.py

(Alternative command):
python pipeline_steps\run_all_steps.py

Option B: Run Steps Individually in Sequence
--------------------------------------------
Step 01 - Load Dataset & Directory Validation:
python pipeline_steps\step01_load_dataset.py

Step 02 - Data Preprocessing & Formatting:
python pipeline_steps\step02_data_preprocessing.py

Step 03 - Data Leakage Checks (Target, Duplicates, Suspicious Features):
python pipeline_steps\step03_data_leakage_checks.py

Step 04 - CLAHE Contrast-Limited Adaptive Histogram Equalization:
python pipeline_steps\step04_clahe_enhancement.py

Step 05 - Train / Val / Test Splits (80:20 and 5-Fold Stratified):
python pipeline_steps\step05_train_val_test_splits.py

Step 06 - GAN Augmentation on Training Data Only:
python pipeline_steps\step06_gan_augmentation.py

Step 07 - Initial Model Training:
python pipeline_steps\step07_initial_model_training.py

Step 08 - Overfitting / Underfitting Detection & Diagnostics:
python pipeline_steps\step08_overfit_underfit_detection.py

Step 09 - Apply Correction Techniques & Retraining:
python pipeline_steps\step09_correction_and_retrain.py

Step 10 - Final Test Evaluation & Metrics Export:
python pipeline_steps\step10_final_test_evaluation.py
